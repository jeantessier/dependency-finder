The original =test.java=:

    import java.util.*;
    &nbsp;
    public class test {
        public static void main(String[] args) {
            Collection c = Collections.singleton(new Object());
        }
    }

Becomes:

    void main() {
        Collection c = Collections.singleton(new Object());
    }

And it loses the explicit dependency on =java.lang.String=.

These are shortcuts for beginner programmers learning Java.  I wouldn't write a
large application in compact source files.  The Manual's examples are
deliberately simple so they can show how the tools track dependencies, but they
should still be representative of the code that users actually write.
